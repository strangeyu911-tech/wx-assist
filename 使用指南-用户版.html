摘星 · 微信助手

把微信群聊、公众号、收藏和朋友圈变成可检索、可提醒、可对话的个人知识库。本指南面向直接下载安装包使用的用户，全程无需接触代码。

Windows 10 / 11 安装包即下即用 数据全程本机

这是什么

摘星是一款运行在你自己的电脑上的微信辅助工具：它读取本机微信的聊天数据，配合 AI 提供摘要、提醒、检索和对话能力。所有核心数据处理都在本机完成。

群聊 AI 摘要
多个群打包成一组，定时生成一份合并摘要，AI 自动标注待办与决定，漏看群消息不再慌。
关键词提醒
给群聊设置关注词，命中后即时推送到你的微信 / QQ / 飞书，重要消息不错过。
公众号助手
关注的公众号按主题分组，定时汇总新文章生成速读摘要，即时提醒新发文。
多平台推送
绑定微信机器人、QQ 机器人或飞书，扫码即用，摘要和提醒想发到哪就发到哪。
AI 对话与 Agent
基于聊天记录、收藏、朋友圈的上下文直接提问；Agent 能调用 20+ 工具帮你查状态、搜消息、管配置。
收藏 / 朋友圈归档
收藏内容整理检索，朋友圈导出为离线档案，聊天记录一键打包成 HTML。

使用前必读

⚠️ 请先花两分钟了解使用边界

本项目的消息推送走微信官方机器人通道（iLink），这部分是安全的。但工具同时具备读取本地微信数据、辅助操作微信的能力——这类用法不在微信官方许可范围内，存在账号被限制甚至封禁的可能。

使用前请务必阅读 风险告知，了解哪些功能安全、哪些功能有风险、如何把风险降到最低。最核心的一条：让机器人代收摘要和提醒，不要让工具用你的真实微信号自动发消息。

下载与安装

去哪里下载

打开仓库的 Releases（发行版） 页面：github.com/strangeyu911-tech/wx-assist/releases，在最新版本的 Assets（附件） 区域下载安装文件。

关于 Release 附件，请先了解三件事

1. 不是每个版本都带附件。部分历史版本（例如 v1.5.1）只发布了版本说明、没有上传安装文件。下载时认准 Assets 区域里确实挂着 .exe 文件的版本，不要只看版本号最新。

2. 安装文件本身就是完整的。程序运行需要的全部组件（包括解密组件、界面、AI 语义检索模型）都已经打包在 .exe 内部——下载一个文件、双击就能用，安装完成后不需要再额外安装任何附件。

3. 附件区里的 zip / tar.gz 是给开发者准备的。那是「从源码运行」路线需要的组件包，普通用户不需要下载。细节见开发者版指南。

选哪个版本

安装文件体积区别适合
wx-assist.exe
完整版		 约 190 MB 包含全部功能，含 AI 语义检索（RAG）。首次启动会为历史内容建索引，约 1–5 分钟。 想要完整体验、不介意体积
wx-assist_no_rag.exe
精简版		 约 76 MB 仅去掉本地语义检索，其余功能完全一样。即开即用，无需建索引。 追求轻量、主要用摘要和提醒
拿不准就选精简版

核心功能（群摘要、关键词提醒、公众号助手、多平台推送、AI 对话）两个版本都有。语义检索只影响 AI 回答时「按意思找内容」的精准度，不影响日常使用，以后想补装再下完整版即可。

杀毒软件提示「有风险」？

安装文件使用 PyInstaller 打包，部分杀毒软件可能误报。这属于此类打包工具的常见现象。可在杀软中添加信任/排除项；如果不放心，也可以选择从源码运行（见开发者版指南），全程自己本机编译。

首次运行

  1. 确保微信电脑版已安装并登录程序启动时会检测微信进程。请先把微信电脑版打开并登录，再进行下一步。手机版微信无法替代。
  2. 把 .exe 放到一个固定的文件夹建议新建一个专用文件夹（例如 D:\wx-assist\）把 .exe 放进去。程序会在旁边自动创建 data\ 文件夹存放全部配置和数据。
  3. 双击运行第一次运行会初始化数据，稍等几秒会弹出程序窗口（完整版首次启动还会建索引，期间界面可以正常打开）。也可以在浏览器访问 127.0.0.1:17327 打开同一界面。
  4. 以后每次使用先登录微信电脑版 → 双击 .exe。不想让它开机自启就不用管，随用随开。
升级与卸载

升级：下载新版 .exe，关掉旧窗口后用它覆盖旧文件即可——所有配置和数据都在 data\ 文件夹里，不会丢失。卸载：直接删除整个文件夹，不留残余、不写注册表。

绑定推送平台

摘要、提醒生成后要送到哪里？在 系统配置 → 推送平台 里绑定。推荐至少绑定微信机器人——这是微信官方提供的机器人通道，安全性最高。

  1. 绑定微信机器人（推荐）进入「系统配置 → 推送平台 → 微信」，点「生成二维码」，用手机微信扫码确认。绑定成功后，界面会显示「已连接」。这是官方通道，摘要、提醒、Agent 回复都会由机器人私聊发给你。
  2. 绑定 QQ 机器人（可选）在「QQ」页生成二维码，用手机 QQ 扫码并在手机上确认授权。注意：QQ 的授权任务约 5 分钟内有效，扫码后请停留在绑定页等待，超时就取消重新生成。绑定过程需要电脑保持联网。
  3. 绑定飞书（可选）同样扫码绑定，流程类似。
  4. 设置默认投递渠道绑定完成后，在推送设置里为摘要、提醒等任务选择投递平台。建议全部走机器人私聊。
扫码后手机一直显示「连接中」？

手机端页面显示不准不影响绑定，以电脑端界面为准：电脑端显示「已连接 / 已绑定」就是成功了。QQ 授权若超过 5 分钟未完成会过期，重新生成二维码再扫一次即可。

配置 AI 后端

摘要、提醒、对话都依赖 AI 模型。进入「系统配置 → AI 设置」，页顶有两个接入方式可选：「WorkBuddy 应用服务」和「API Key 接入」。两种方式二选一即可。

方式一：WorkBuddy 应用服务（推荐，最简单）

如果你电脑上装有 WorkBuddy 桌面应用并已登录，这是最省事的方式：不需要注册任何大模型服务、不需要充值、不需要填写 API Key——程序直接复用你本机 WorkBuddy 登录账号的模型额度。

  1. 确保 WorkBuddy 已安装并登录在本机安装 WorkBuddy 桌面应用，并登录你的账号。程序会自动找到它，无需手动配置路径。
  2. 切换接入方式进入「系统配置 → AI 设置」，点页顶的「WorkBuddy 应用服务」按钮。页面会显示检测状态：找到 WorkBuddy 即说明就绪。
  3. 点「测试连接」模型选择保持默认（自动）即可。测试通过后，「运行状态」页的 AI 后端会显示「可达」。
  4. 保存并重启程序保存设置后重启摘星（关掉窗口重新双击 .exe）即可生效。
什么时候选这种方式？

已经（或愿意）安装 WorkBuddy、不想折腾大模型注册和充值的用户——一步切换、点一次测试就能用。如果不想额外安装应用，或者想用特定的大模型服务（如 DeepSeek），选下面的方式二。

方式二：API Key 接入

  1. 获取一个 API Key到大模型服务商官网注册并创建 API Key（例如 DeepSeek，充值几块钱够用很久）。
  2. 填入程序在「系统配置 → AI 设置」里点「API Key 接入」，粘贴 API Key，选择模型，保存。
  3. 点「测试连接」测试通过后，「运行状态」页的 AI 后端会显示「可达」。第一次使用前务必点一次。
API Key 是你的私密凭证

Key 只保存在本机 data\ 文件夹中，不会随聊天记录或导出档案泄露。不要把 key 发给别人、不要截图外传。

日常使用

群聊摘要

在「群聊助手」里把想追踪的群加入分组，设置生成频率（如每天早晚各一次）。到点后 AI 会把整组群的未读消息合并成一份摘要：按群分段、标注待办与重要决定，推送到你绑定的机器人私聊里。

关键词提醒

给群聊设置关注词（如项目名、你的名字），消息命中后即时推送，附上下文原文链接。

公众号速读

关注的公众号按主题分组，新文章发布即推送 AI 速读；也可以定时收到一份汇总。

Agent 对话

在机器人对话里直接@或私聊 Agent：「帮我找上周王总发的那份文件」「现在几点了，提醒我三点开会」——它会调用工具完成并回复。所有对话都发生在机器人私聊中，不会打扰你的群。

窗口能开，但显示「未检测到微信」先启动并登录微信电脑版，再重启摘星。程序只支持 Windows 版微信。

安全使用提示

🟢 放心用

微信 / QQ / 飞书机器人私聊推送、本机的摘要生成、收藏与朋友圈归档、关键词提醒——这些是这款工具的日常用法。

🟡 知情使用

读取本机微信数据库属于灰色地带：违规但纯本地、对外不可见。请只在自己电脑上使用，不要把工具或数据档案转给他人。

🔴 不要用

不要开启任何「用你的真实微信号自动发消息」的功能，不要配合抢红包、批量加好友、营销群发等外挂插件使用。这些是微信官方明令打击的行为，可能危及主号。

一句话原则：机器人负责把信息送到你面前，发不发、发什么，由你亲手决定。
